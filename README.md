# 🎁 Birthday Magic Box ✨

A magical and interactive **Birthday Wishes web project** built using **HTML, CSS, and JavaScript**.

The project creates a fun birthday experience where the user opens an animated gift box to reveal a birthday celebration with a cake, balloons, sparkles, wishes, and colorful confetti.

## 🎮 How It Works

### 1. 🎁 Open the Magic Box

Click the **OPEN THE MAGIC** button or click the gift box.

The gift box:

* Shakes
* Opens its lid
* Moves upward
* Releases colorful confetti
* Reveals the birthday celebration

### 2. 🎉 Birthday Reveal

After the gift opens, the page displays:

* HAPPY BIRTHDAY message
* Animated cake
* Flickering candles
* Birthday person's name
* Special birthday wishes

### 3. 🕯️ Make a Wish

Click **MAKE A WISH**.

The project then:

* Extinguishes the candle flames
* Changes the button to **WISH SENT**
* Creates another burst of confetti
* Reveals the final birthday message

## ⚡ JavaScript Interactions

JavaScript controls the main interactive features:

```javascript
openGift()
```

Opens the gift box and starts the birthday reveal.

```javascript
createConfetti(180)
```

Creates a colorful confetti animation.

```javascript
wishBtn
```

Handles the **Make a Wish** interaction.

The candles are extinguished when the wish button is clicked.
